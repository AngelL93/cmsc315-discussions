This assignment uses Python dictionaries to demonstrate hash table behavior.

- Remove entries
- Understand hashing concepts

3. Explain how hash tables behave, what collisions are, and how hash tables can improve efficiency.

Hash tables use a hash function to determine where information is stored. A collision happens when two different keys map to the same location. 
It handles collisions internally so the dictionary can still work correctly. 
Hash tables improve efficiency because they allow information to be found, added, or updated quickly in most situations.
