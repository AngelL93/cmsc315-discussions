3. Explain the differences between stacks and queues as this relates to real-world applications.

The biggest difference is the order in which values are removed. Stacks follow Last In, First Out (LIFO), while queues follow First In, First Out (FIFO). 
For my Starbucks example, a queue makes more sense because customers should be served in the order they arrive, rather than serving the last person first.
